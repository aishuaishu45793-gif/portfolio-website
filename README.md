# 🌐 Portfolio Website

A modern and responsive personal portfolio website created to showcase my **skills, projects, education, experience, and contact information**.

This portfolio provides a simple and professional way for recruiters, developers, and visitors to learn more about me and explore my work.

## ✨ Features

* 🏠 Home section
* 👩‍💻 About Me section
* 🛠️ Skills section
* 📂 Projects section
* 🎓 Education section
* 💼 Experience section
* 📞 Contact section
* 📱 Responsive design
* 🎨 Modern and clean user interface
* 🔗 Social media / GitHub links

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
* **Git** – Version control
* **GitHub** – Source code hosting

## 🚀 How to Run the Project

### 1. Clone the repository

Open your terminal and run:

```bash
git clone https://github.com/aishuaishu45793-gif/portfolio-website.git
```

### 2. Open the project

Move into the project folder:

```bash
cd portfolio-website
```

### 3. Open in VS Code

Run:

```bash
code .
```

Or open the `portfolio-website` folder manually in Visual Studio Code.

### 4. Run the website

If the project is a basic HTML/CSS/JavaScript website, you can open:

```text
index.html
```

directly in your browser.

For an easier development experience, you can install the **Live Server** extension in VS Code and click:

```text
Go Live
```

The website will then open in your browser.

## ⚙️ How the Project Works

The portfolio website is divided into different sections.

### 1. Home

The home section introduces me and provides quick navigation to the rest of the portfolio.

### 2. About

The About section provides information about my background, interests, and career goals.

### 3. Skills

The Skills section displays the programming languages, technologies, and tools that I have learned.

### 4. Projects

The Projects section showcases my development projects with descriptions and links to their source code or live demonstrations.

### 5. Education

The Education section provides information about my educational background.

### 6. Contact

The Contact section allows visitors to find my contact information and connect with me.
